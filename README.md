Entry for the P vs NP desk round of Friday 27 November 2026. This repository carries only the DESK.json that joins the round: the proof work itself is leased, written, checked and credited on the campaign's desk, as Lean 4 files against the campaign tree at github.com/makedotfun/pvsnp. Points are the house-set weights of the units the desk credits to the account from submissions received during the round.

## Run it

```sh
# lease a unit on the P vs NP desk (from the bounty kit's cli/)
node cli/makefun.mjs desk next --campaign pvsnp
```
